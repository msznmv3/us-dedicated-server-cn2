## 先想清楚：你的业务需要哪种线路？

答案取决于你的用户在哪。大陆用户优先直连线路，海外用户走国际 BGP 就够了。

美国服务器的网络大体分两类。第一类是高速直连线路，包括 CN2 GIA（AS4809）、CUII（AS9929）、CMIN2（AS58807）、三网 AS4837 和直连 BGP，特点是大陆访问延迟低、晚高峰相对稳，代价是单价贵。第二类是大带宽国际线路，走国际出口，10Gbps 起步的带宽很常见，价格便宜不少，部分还带 DDoS 防御能力。

按场景套就行：

- 大陆用户为主、对延迟敏感 → CN2 GIA 优先，预算不够再看 AS9929 或 CMIN2；
- 大陆访问要求一般 → AS4837 直连或直连 BGP，性价比更高；
- 用户主要在欧美 → 国际 BGP，把预算花在带宽上更划算；
- 业务有被攻击的风险 → 防御能力单独作为一个指标来比，别指望普通线路顺便扛攻击。

### 站群服务器的 4C、8C 是什么意思？

C 指 C 段，一个 C 段是 /24 的 IP 段，约 256 个 IPv4，4C 就是 4 个 C 段。RackNerd 的站群服务器提供 4C/8C/16C/32C 可选；如果只需要几十个 IP，也有单机 100 个 IPv4 的配置，比如 Lightlayer 的 CN2+CMIN2 机型。
